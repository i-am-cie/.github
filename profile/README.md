## 📌 我的项目

### 🧪 AI 软件测试工具链（基于 Ollama 本地大模型，完全离线）

一套覆盖测试全流程的本地工具，从需求分析一路到性能测试：

| 测试阶段 | 项目 | 说明 |
| --- | --- | --- |
| 需求分析 | [ai-test-generator](https://github.com/i-am-cie/ai-test-generator) | 从需求/代码生成测试用例，支持 JSON/CSV 导出 |
| 代码审查 | [code-review-assistant](https://github.com/i-am-cie/code-review-assistant) | 全面 / 安全 / 风格三种模式本地代码审查 |
| 接口测试 | [api-test-assistant](https://github.com/i-am-cie/api-test-assistant) | 生成 API 测试用例、自动发请求、AI 分析结果 |
| 数据测试 | [sql-test-assistant](https://github.com/i-am-cie/sql-test-assistant) | 数据质量检查 SQL、用例生成、表结构审查 |
| UI 自动化 | [e2e-test-generator](https://github.com/i-am-cie/e2e-test-generator) | 生成 Selenium / Playwright 端到端测试脚本 |
| 性能测试 | [perf-test-assistant](https://github.com/i-am-cie/perf-test-assistant) | 生成 Locust 脚本、测试策略、压测结果分析 |
